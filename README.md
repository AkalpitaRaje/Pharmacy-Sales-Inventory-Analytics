# Pharmacy Sales & Inventory Analytics

## Project Overview
This project analyzes pharmacy sales and inventory data using Python and data analysis libraries. It focuses on data quality, data cleaning, sales performance, inventory levels, and medicine expiry analysis.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV Datasets

## Project Structure
```text
Pharmacy-Sales-Inventory-Analytics/
├── data/
│   ├── pharmacy_sales_inventory.csv
│   ├── pharmacy_sales_inventory_cleaned.csv
│   └── pharmacy_sales_inventory_final.csv
├── data_cleaning.py
├── data_quality_check.py
├── generate_dataset.py
├── feature_engineering.py
├── sales_analysis.py
├── visualization.py
├── expiry_analysis.py
└── inventory_analysis.py
```

## Key Features
- Dataset generation and data quality checks
- Data cleaning and feature engineering
- Sales performance analysis
- Inventory level analysis
- Medicine expiry analysis
- Data visualization

## Datasets
The project includes original, cleaned, and final pharmacy datasets in CSV format.

## Purpose
The goal of this project is to practice Python-based data analysis and demonstrate how sales and inventory data can support better business decisions.
